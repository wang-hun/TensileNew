# 圆环外缘缺陷检测 API

服务地址：`http://<服务器地址>:<端口>`（默认 `5080`）

---

## 一、接口一览

| 方法 | 路径 | 传图方式 | 说明 |
|---|---|---|---|
| POST | `/api/detect/blob/strict` | 请求体 = 图片原始字节 | 默认参数 + 严格模式（推荐） |
| POST | `/api/detect/blob` | 请求体 = 图片原始字节 | 可改参数（参数走 query） |
| POST | `/api/detect/path/strict` | JSON 传路径 | 默认参数 + 严格模式 |
| POST | `/api/detect/path` | JSON 传路径 | 可改参数 |
| POST | `/api/detect/path/batch` | JSON 传路径数组 | 批量，≤64 张 |
| POST | `/api/detect/strict` | JSON 传 base64 | 默认参数 + 严格模式 |
| POST | `/api/detect` | JSON 传 base64 | 可改参数 |
| POST | `/api/detect/batch` | JSON 传 base64 数组 | 批量，≤64 张 |
| GET | `/api/health` | — | 健康检查 |
| GET | `/api/params` | — | 查参数默认值与范围 |

---

## 二、入参

### 2.1 图片与通用参数

| 参数 | 类型 | 必填 | 默认 | 适用接口 | 含义 |
|---|---|---|---|---|---|
| `body` | 二进制 | blob 模式必填 | — | blob | 图片原始字节，`Content-Type: application/octet-stream` |
| `path` | string | path 模式必填 | — | path | 图片路径，绝对路径或相对允许根目录；别名 `file` |
| `paths` | string[] | batch 必填 | — | path/batch | 路径数组，1~64 条 |
| `image` | string | base64 必填 | — | base64 | 图片 base64，可带 `data:image/...;base64,` 前缀 |
| `fileName` | string | 否 | 空 | 全部 | 文件名，仅回显 |
| `strict` | bool | 否 | `true` | 全部 | 严格模式：必须"缺口 + 尖刺"配对才判 NG |
| `includeProfile` | bool | 否 | `false` | 全部 | 返回外缘轮廓曲线（自己画图时用） |
| `includeOverlay` | bool | 否 | `false` | 全部 | 返回服务端画好的结果图（PNG，体积大） |
| `params` | object | 否 | 默认值 | path / base64 | 17 个检测参数覆盖，见 2.3 |

### 2.2 blob 模式参数位置

`body` 放图片，其余参数走 query string：

```
POST /api/detect/blob?strict=false&fileName=a.bmp&debrisTh=222
```

### 2.3 17 个检测参数

| 参数 | 默认 | 含义 |
|---|---|---|
| `darkTh` | 128 | 比它暗的像素算零件本体 |
| `debrisTh` | 240 | 比它暗的算可疑碎屑，越大越敏感 |
| `gap` | 3 | 离边缘多远开始找碎屑 |
| `band` | 70 | 检测区域宽度 |
| `minArea` | 14 | 碎屑最小面积（px²） |
| `minReach` | 12 | 尖刺最小伸出长度（px） |
| `minElong` | 2.2 | 尖刺最小细长比 |
| `notchDepth` | 14 | 缺口最小深度（px） |
| `notchMinWidth` | 1 | 缺口最小宽度（°） |
| `baselineWin` | 20 | 基线参考窗口（°） |
| `pairDist` | 40 | 缺口与尖刺最大间距（px） |
| `bigNotchDepth` | 30 | 大缺口独立判 NG 的深度，0=关闭 |
| `breakMinWidth` | 11 | 断口弧长小于此值（px，按 R=500 计）当作零件自带开口，不判断裂 |
| `loneDebrisNG` | `true` | 细长尖刺单独出现也判 NG |
| `strictPair` | `true` | 严格模式开关 |
| `angFrom` | 0 | 检测起始角度（°，0=正右，顺时针） |
| `angTo` | 360 | 检测结束角度（°） |

> 长度/面积参数按"外半径 500px"归一化，实际值 = 参数 × (实测半径/500)。

---

## 三、返回参数

### 3.1 顶层

| 字段 | 类型 | 含义 |
|---|---|---|
| `ok` | bool | 请求是否正常执行（不代表零件合格） |
| `verdict` | string | **判定结果**：`OK` / `NG` |
| `errorCode` | string | 失败时的错误码 |
| `error` | string | 失败时的说明 |
| `fileName` | string | 回显文件名 |
| `timeMs` | number | 算法耗时（ms） |
| `width` / `height` | int | 图片尺寸 |
| `circle` | object | `cx`、`cy` 圆心，`R` 外半径（大写 R） |
| `scale` | number | 尺寸系数 = `R / 500` |
| `ring` | object | `area` 像素数、`bbox` 外接框 |
| `band` | object | `gap`、`band`、`pixels` 检测区域信息 |
| `params` | object | 本次生效的 17 个参数 |
| `scaled` | object | 换算成实际像素后的阈值 |
| `defects` | array | **缺陷清单**，空数组=无缺陷 |
| `candidates` | array | 被过滤的可疑项（排查用，字段同 defects） |
| `defectCount` | int | 缺陷条数 |
| `filteredCount` | int | 被过滤条数 |
| `profile` | object | `n`、`r`、`rBody`、`base`、`dev`、`sigma`，仅 `includeProfile=true` |
| `overlay` | string | 结果图 data URL，仅 `includeOverlay=true` |
| `baseImage` | string | 底图 data URL（JPEG），仅 blob / path 模式 |

### 3.2 `defects[]`

| 字段 | 类型 | 出现于 | 含义 |
|---|---|---|---|
| `id` | int | 全部 | 编号，从 1 开始 |
| `type` | string | 全部 | 类型代码，见 3.3 |
| `typeName` | string | 全部 | 类型中文名 |
| `angle` | number | 全部 | 角度（°，0=正右，顺时针，90=正下） |
| `x` / `y` | number | 全部 | 缺陷中心坐标 |
| `bbox` | number[4] | 全部 | 外接框 `[左, 上, 右, 下]` |
| `depthPx` | number | 缺口类 | 缺口深度（px） |
| `depthNorm` | number | 缺口类 | 缺口深度（归一化值） |
| `widthDeg` | number | 缺口类 | 缺口宽度（°） |
| `arcLenPx` | number | 缺口类 | 缺口弧长（px） |
| `angFrom` / `angTo` | number | 缺口类 | 缺口起止角度（°） |
| `areaPx` | int | 尖刺类 | 尖刺/异物面积（px²） |
| `sizePx` | int[2] | 尖刺类 | 外接宽高 `[宽, 高]` |
| `reachPx` | number | 尖刺类 | 伸出外缘长度（px） |
| `minLum` | int | 尖刺类 | 最暗灰度（0~255） |
| `spikeCount` | int | paired | 配到的尖刺数 |
| `notchBox` | number[4] | paired | 缺口外接框 |
| `debrisBox` / `debrisBoxes` | number[4] | paired | 尖刺外接框（可多个） |
| `gapPx` | number | paired | 缺口与尖刺最小间距（px） |

### 3.3 `type` 取值

| `type` | `typeName` |
|---|---|
| `paired` | 缺口伴生尖刺/异物 |
| `bignotch` | 大缺口（无尖刺） |
| `broken` | 圆环断裂（断口整条径向都没有材料，字段见 3.2；`depthPx` 恒 0） |
| `notch` | 外缘缺口 |
| `debris` | 外缘异物/碎屑 |
| `burr` | 外缘毛刺/飞边 |

### 3.4 批量接口返回

| 字段 | 类型 | 含义 |
|---|---|---|
| `total` | int | 总张数 |
| `ok` / `ng` / `err` | int | OK / NG / 失败 张数 |
| `elapsedMs` | number | 服务端总耗时 |
| `results` | array | 每张的 `DetectResult` |

---

## 四、错误码

| `errorCode` | HTTP | 含义 |
|---|---|---|
| `MISSING_IMAGE` | 400 | 没传图片/请求体为空 |
| `INVALID_JSON` | 400 | 请求体不是合法 JSON，或字段类型不匹配 |
| `INVALID_PARAM` | 400 | 参数名错误或值非法 |
| `BAD_PATH` | 400 | 路径不存在/越界/格式不支持 |
| `EMPTY_BATCH` | 400 | `paths` 为空 |
| `BATCH_TOO_LARGE` | 400 | 超过 64 张 |
| `DECODE_FAILED` | 200 | 图片解不开（该条 `ok=false`） |
| `NO_RING` | 200 | 图里没找到圆环 |
| `FIT_FAILED` | 200 | 拟合圆失败 |
| `INTERNAL_ERROR` | 500 | 服务内部异常 |

## 五、最小示例

请求：

```bash
curl -X POST "http://<服务器地址>:<端口>/api/detect/blob/strict?fileName=a.bmp" \
     -H "Content-Type: application/octet-stream" \
     --data-binary "@a.bmp"
```
